# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it by opening a new issue or contacting the maintainers directly. We take all security reports seriously and will respond as promptly as possible.

## Code Scanning

**Code scanning is mandatory** for this repository. All code contributions and pull requests must pass code scanning checks before being merged. We use automated tools to detect vulnerabilities and ensure best practices are followed.

## Rule Set

A strict security rule set is enforced in this repository. All contributors must adhere to the repository’s security guidelines and code scanning requirements. PRs that fail security rule reviews will not be merged.

## Additional Guidelines

- Keep dependencies up to date to avoid exposure to known vulnerabilities.
- Never commit secrets or sensitive information to the repository.
- Follow the principle of least privilege in all contributions.

Thank you for helping keep this project secure!
